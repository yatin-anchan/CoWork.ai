- Project-based AI workspace
- Multiple chats per project
- Public/private chats
- Project instructions
- Project memory
- Single-model AI responses
- AI Team Mode for Pro users

- Shared projects

- Owner/editor/viewer roles
- Member role management

- Message retry
- Message edit
- Versioned messages
- Copy messages
- Export TXT/PDF

- File context injected into AI
- Rename files
- Delete files
- Show file chat scope
- Free: 5 files
- Pro: 30 files

## Auth
- Login/register
- Extended registration details
- Forgot password
- Reset password
- Profile edit
- Change password

## Analytics
- Sidebar token card for all users
